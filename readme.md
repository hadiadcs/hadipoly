# 🎲 Hadipoly

Hadipoly is a digital board game inspired by the classic Monopoly, redesigned with custom rules, modern features, and a sleek UI.  
The game combines **strategy, luck, and financial management** into a fun and interactive experience.

---

## 🚀 Features
- 🏠 Buy, sell, and trade properties  
- 💰 Manage in-game currency and assets  
- 🎡 Random events and chance cards for surprises  
- 🎮 Multiplayer support (local/online planned)  
- 📊 Customizable rules for unique gameplay  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Bootstrap for styling)  
- **Backend (if applicable):** Python / Node.js  
- **Database:** SQLite / MongoDB
